# Roadmap

## Phase 1 — Geometry Prototype

- Calculation Core แบบ pure functions
- Validation รายช่อง
- Live pipe preview
- Export project JSON
- Automated formula tests
- GitHub Pages deployment

## Phase 2 — Engineering Solver

- Engine identity และ project metadata
- Bore, stroke, displacement และ connecting-rod length
- Exhaust/transfer timing และ port geometry
- Tuned-length solver
- Cone angle, area ratio และ stinger safety checks
- เปรียบเทียบหลาย design revisions

## Phase 3 — Online Projects

- Authentication และ role-based access
- Project database และ autosave
- Revision history
- Customer sharing
- Server-side calculation สำหรับสูตรที่เป็นทรัพย์สินทางปัญญา

## Phase 4 — Manufacturing Output

- Dimensioned drawing
- Cone development
- SVG/DXF/PDF export
- Material thickness และ fabrication allowances
- Controlled validation ก่อนส่งผลิต
